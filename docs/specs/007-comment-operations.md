# 规格七：评论运营

## 1. 目标

准确采集评论、识别风险、自动回复低风险评论，并将高风险内容升级人工。

覆盖需求：

- `REQ-COM-001` 至 `REQ-COM-015`
- `REQ-INS-001` 至 `REQ-INS-006`

## 2. 默认策略

- 自动回复仅覆盖低风险；
- 每帖每小时最多三条；
- 全账号每日最多二十条；
- 相邻回复间隔八至十五秒；
- 单轮最多三条；
- 每个发送动作只发一条；
- 任一平台风控提示触发全账号评论熔断；
- 人工明确恢复后才继续。

## 3. 评论事件

```json
{
  "comment_event_id": "唯一标识",
  "account_id": "账号标识",
  "post_id": "帖子标识",
  "external_comment_id": "平台评论标识",
  "author_id": "脱敏作者标识",
  "author_name": "展示名",
  "text": "评论文本",
  "commented_at": "时间",
  "collected_at": "时间",
  "parent_comment_id": null,
  "status": "new"
}
```

平台没有稳定评论标识时，使用帖子、作者、时间和文本摘要构造候选标识，并标记可靠性。

## 4. 分类

类别：

- `ordinary_interaction`
- `simple_question`
- `correction`
- `disagreement`
- `potential_need`
- `spam`
- `sensitive`
- `unknown`

风险等级：

- `low`
- `medium`
- `high`
- `blocked`

自动回复条件：

- 类别为普通互动或简单追问；
- 风险为低；
- 目标对象校验可靠；
- 未触发频率限制；
- 评论自动化未暂停；
- 没有已成功回复；
- 回复通过内容检查。

## 5. 必须人工处理

- 纠错且无法立即用来源核验；
- 激烈争议或人身攻击；
- 投诉；
- 法律、医疗、金融等敏感建议；
- 要求私下交易或提供敏感信息；
- 外链诱导、钓鱼；
- 要求公开密钥、配置或隐私；
- 身份或回复对象不明确；
- 平台风控提示；
- 模型分类置信度不足。

## 6. 分类技能

技能名称：`comment_triage`

输入：

- 帖子摘要；
- 原评论；
- 必要的上下文；
- 账号策略；
- 自动回复策略；
- 已有回复历史。

输出：

```json
{
  "category": "simple_question",
  "risk": "low",
  "confidence": 0.91,
  "reasons": ["问题范围明确"],
  "requires_fact_check": false,
  "is_problem_candidate": true,
  "recommended_action": "auto_reply"
}
```

置信度低于配置阈值时升级人工。

## 7. 回复生成

技能名称：`reply_writing`

约束：

- 建议不超过二百八十字；
- 一至四行；
- 先回应评论本身；
- 最多给一个关键建议；
- 不虚构个人经历；
- 不承诺未来必然交付；
- 不索取手机号、邮箱等敏感信息；
- 不使用重复模板连续刷屏；
- 涉及事实时使用已核验证据；
- 保留自然的可追问点。

回复版本：

- 原评论变化后旧版本失效；
- 人工修改创建新版本；
- 新版本重新执行风险检查。

## 8. 发送流程

```text
领取一条待回复评论
→ 检查暂停和限流
→ 打开通知页
→ 定位目标通知
→ 点击回复
→ 校验“回复 <用户名>”
→ 输入文本
→ 再次校验对象
→ 点击发送
→ 确认输入框清空或回复可见
→ 保存结果
```

不得使用回车作为默认发送动作。

## 9. 对象校验

发送前至少校验：

- 当前账号；
- 帖子；
- 评论作者；
- 评论关键文本；
- 回复输入框目标用户名。

任一不匹配立即取消，不尝试猜测。

## 10. 限流

`rate_limit_buckets` 保存：

- 账号；
- 帖子；
- 动作；
- 窗口类型；
- 窗口开始；
- 已用数量；
- 上限；
- 最近动作时间。

额度扣减与回复动作准备在一个事务中完成。发送失败后是否返还额度由错误类型决定：

- 明确未发送：可以返还；
- 结果未知：不返还，先核验；
- 平台风控：不返还并熔断。

## 11. 熔断

触发：

- 评论过于频繁；
- 操作过快；
- 请稍后再试；
- 连续两次发送失败；
- 回复对象持续漂移；
- 登录失效；
- 检测到错误账号。

熔断后：

- 停止领取评论回复工作项；
- 保留待处理队列；
- 飞书告警；
- 记录触发证据；
- 等待人工恢复。

## 12. 用户问题候选

若评论包含具体场景、任务或限制，创建 `problem_candidates`：

- 脱敏评论引用；
- 用户任务；
- 使用场景；
- 限制；
- 尝试结果；
- 来源帖子；
- 分类置信度；
- 是否已人工确认。

问题候选进入聚类，但不自动视为商业需求。

## 13. 错误代码

| 错误码 | 处理 |
|---|---|
| `COMMENT_TARGET_UNCERTAIN` | 人工 |
| `COMMENT_ALREADY_REPLIED` | 幂等结束 |
| `COMMENT_RATE_LIMITED` | 延后 |
| `COMMENT_RISK_BLOCKED` | 人工 |
| `COMMENT_REPLY_INVALID` | 重写一次 |
| `COMMENT_SEND_UNCERTAIN` | 核验 |
| `COMMENT_PLATFORM_THROTTLED` | 熔断 |
| `COMMENT_WRONG_ACCOUNT` | 熔断并告警 |

## 14. 验收条件

- `AC-007-01` 中高风险评论不会自动回复。
- `AC-007-02` 对象校验不通过时不会发送。
- `AC-007-03` 单个发送动作只产生一条回复。
- `AC-007-04` 同一回复版本重复触发不会重复发送。
- `AC-007-05` 每帖、每小时和每日上限均生效。
- `AC-007-06` 风控提示会立即熔断。
- `AC-007-07` 熔断后只有授权人工可以恢复。
- `AC-007-08` 回复不包含虚构经历和隐性承诺。
- `AC-007-09` 有效问题候选完成脱敏并进入问题库。

## 15. 测试重点

- 同名用户；
- 评论被删除；
- 回复对象在输入后漂移；
- 发送成功但确认失败；
- 限流并发扣减；
- 午夜跨日；
- 风控提示；
- 恶意提示词注入评论；
- 包含联系方式；
- 纠错评论的事实核验。
