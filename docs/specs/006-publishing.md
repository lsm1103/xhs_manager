# 规格六：排期与发布

## 1. 目标

在有效发布审批覆盖范围内，按计划安全完成小红书图文发布，并严格处理重复执行和结果未知。

覆盖需求：

- `REQ-PUB-001` 至 `REQ-PUB-012`

## 2. 前置条件

- 内容任务状态为 `scheduled`；
- 发布计划未取消；
- 发布自动化未暂停；
- 当前时间进入允许窗口；
- 账号和浏览器会话健康；
- 内容版本完整；
- 发布审批有效；
- 不存在成功或结果未知的同幂等动作。

## 3. 发布计划

```json
{
  "publication_plan_id": "唯一标识",
  "task_id": "任务标识",
  "account_id": "账号标识",
  "platform": "xiaohongshu",
  "content_version_id": "内容版本",
  "approval_id": "发布审批",
  "scheduled_at": "带时区时间",
  "allowed_from": "允许窗口开始",
  "allowed_until": "允许窗口结束",
  "status": "scheduled",
  "idempotency_key": "唯一业务键"
}
```

## 4. 发布记录

保存：

- 计划；
- 实际开始和结束时间；
- 内容版本；
- 审批；
- 浏览器会话标识；
- 外部帖子标识；
- 帖子地址；
- 结果状态；
- 发布前快照；
- 发布后证据；
- 重试次数；
- 错误。

结果状态：

- `succeeded`
- `failed`
- `uncertain`
- `cancelled`

## 5. 执行阶段

### 5.1 预检

1. 重新读取任务、计划、内容和审批；
2. 校验账号；
3. 校验紧急暂停；
4. 校验发布时间窗口；
5. 校验幂等动作；
6. 检查 OpenClaw 状态；
7. 确认登录有效。

任何一项失败都不得打开最终发布动作。

### 5.2 准备编辑页

1. 启动或复用 `openclaw` 配置；
2. 打开创作入口；
3. 明确选择图文发布；
4. 上传全部图片；
5. 确认进入图文编辑页；
6. 输入标题；
7. 输入正文；
8. 添加话题；
9. 校验封面、标题和正文；
10. 校验标题长度；
11. 保存发布前快照。

上传文件必须先进入浏览器允许的上传目录。

### 5.3 最终提交

点击发布前再次：

- 读取暂停状态；
- 校验任务仍为 `publishing`；
- 校验审批仍有效；
- 校验内容版本未变化；
- 校验按钮和页面状态。

通过后只执行一次最终点击。

### 5.4 结果核验

按顺序检查：

1. 页面明确成功提示；
2. 页面跳转或返回帖子标识；
3. 账号发布列表出现匹配内容；
4. 标题、时间和首图摘要匹配。

核验成功后保存帖子标识和地址。

## 6. 结果未知

以下情况进入 `uncertain`：

- 点击后网络断开；
- 页面无响应；
- 浏览器进程退出；
- 成功提示无法读取；
- 系统崩溃且外部动作已开始。

处理：

1. 不再次点击发布；
2. 新建核验工作项；
3. 检查账号主页和发布记录；
4. 找到匹配帖子则标记成功；
5. 明确未发布才允许一次重试；
6. 无法判断则转人工。

## 7. 重试

- 页面引用失效：刷新快照后重试一次；
- 上传入口失败：尝试同义图文入口一次；
- 临时网络错误：同一外部动作重试一次；
- 登录失效：不自动重试，转人工；
- 风控提示：立即停止；
- 结果未知：先核验，不能直接重试。

## 8. 幂等键

```text
xiaohongshu:<account_id>:<task_id>:<content_version_id>:<publication_plan_id>
```

相同键对应的请求摘要不同，返回 `IDEMPOTENCY_CONFLICT`。

## 9. 取消与延期

- 准备发布页之前可以取消；
- 准备完成但未点击发布时，取消必须关闭或清空草稿并保存证据；
- 最终点击后不能以取消替代结果核验；
- 超出允许窗口不自动补发；
- 延期若超出审批允许窗口，发布审批失效。

## 10. 错误代码

| 错误码 | 处理 |
|---|---|
| `PUBLISH_APPROVAL_INVALID` | 重新审批 |
| `PUBLISH_WINDOW_MISSED` | 重新排期 |
| `BROWSER_UNAVAILABLE` | 重试一次后人工 |
| `LOGIN_REQUIRED` | 人工登录 |
| `WRONG_ACCOUNT` | 立即停止 |
| `UPLOAD_FAILED` | 同义入口重试一次 |
| `CONTENT_INCOMPLETE` | 返回制作 |
| `PUBLISH_RATE_LIMITED` | 熔断并人工 |
| `PUBLISH_RESULT_UNCERTAIN` | 创建核验工作项 |
| `PUBLISH_ALREADY_SUCCEEDED` | 幂等返回已有记录 |

## 11. 验收条件

- `AC-006-01` 无有效发布审批不能进入最终提交。
- `AC-006-02` 封面、标题或正文缺失时不能发布。
- `AC-006-03` 同一发布计划重复触发只形成一个帖子。
- `AC-006-04` 点击后响应丢失不会直接再次发布。
- `AC-006-05` 发布前暂停能阻止最终点击。
- `AC-006-06` 登录失效会转人工而非自动登录。
- `AC-006-07` 发布成功保存平台标识、地址和证据。
- `AC-006-08` 连续失败后停止并给出单一人工动作。
- `AC-006-09` 超出允许窗口不会自动补发。

## 12. 测试重点

- 审批在准备过程中失效；
- 紧急暂停竞争；
- 双入口上传；
- 标题超限；
- 最终点击后断网；
- 平台已发布但系统未收到结果；
- 页面出现相似历史帖子；
- 工作进程重启；
- 草稿残留；
- 错误账号登录。
