# 规格四：图文内容生成

## 1. 目标

将已批准选题转换为带证据、可检查、可预览的完整小红书图文内容版本。

覆盖需求：

- `REQ-CON-001` 至 `REQ-CON-011`

## 2. 前置条件

- 内容任务状态为 `producing`；
- 存在有效选题审批；
- 选题版本与任务绑定版本一致；
- 证据包仍可用；
- 账号策略版本可读取；
- 制作自动化未暂停。

## 3. 生成产物

每个内容版本必须包含：

```json
{
  "content_version_id": "唯一标识",
  "task_id": "任务标识",
  "version": 1,
  "topic_version_id": "选题版本",
  "strategy_version_id": "策略版本",
  "title_candidates": ["标题一", "标题二"],
  "selected_title": "最终标题",
  "body": "正文",
  "interaction_question": "互动问题",
  "topics": ["话题一"],
  "cover_script": {},
  "slide_scripts": [],
  "asset_ids": [],
  "source_notes": [],
  "risk_notes": [],
  "generation_manifest_id": "生成清单",
  "status": "draft"
}
```

## 4. 内容结构

### 4.1 标题

- 至少两个候选；
- 优先不超过二十个汉字；
- 不使用无法被正文支持的夸张结论；
- 不虚构数字；
- 不制造无依据的紧迫感；
- 标题结构必须被记录，用于实验。

标题结构枚举：

- `direct_conclusion`
- `question`
- `contrast`
- `failure_lesson`
- `scenario_problem`
- `experiment_result`

### 4.2 正文

推荐逻辑：

```text
用户场景
→ 一句话结论
→ 原理或过程
→ 证据与结果
→ 限制和失败条件
→ 可执行的最小验证
→ 一个互动问题
```

正文必须区分：

- 已核验事实；
- 来源观点；
- 运营者或系统实验经验；
- 推测或建议。

### 4.3 视觉脚本

先生成视觉脚本，再生成图片。

封面脚本字段：

```json
{
  "headline": "封面主标题",
  "subheadline": "可选副标题",
  "visual_metaphor": "视觉隐喻",
  "layout": "布局说明",
  "style_tokens": ["清晰", "技术感", "不过度赛博"],
  "must_include": [],
  "must_avoid": [],
  "aspect_ratio": "3:4"
}
```

单页脚本字段：

- 页码；
- 本页唯一信息目标；
- 主文案；
- 辅助文案；
- 图形或示意；
- 数据来源；
- 字数上限；
- 与前后页关系。

每页只表达一个主要结论。

## 5. 内容生成技能

技能名称：`content_writing`

输入：

- 已批准选题版本；
- 证据包；
- 账号策略；
- 近期内容去重摘要；
- 实验定义；
- 平台格式约束。

输出：

- 标题候选；
- 正文；
- 互动问题；
- 话题建议；
- 来源使用映射；
- 风险声明；
- 视觉脚本。

禁止：

- 使用证据包外的事实性数字；
- 虚构亲测经历；
- 虚构用户反馈；
- 承诺未来必然交付；
- 复制来源长段文字；
- 模仿单一创作者的独特表达；
- 把不确定信息写成确定事实。

## 6. 图片生成

图片生成适配器输入视觉脚本，不直接接收完整研究资料。

流程：

1. 生成封面；
2. 生成内容页；
3. 保存原始文件；
4. 计算校验值；
5. 生成低分辨率预览；
6. 进行尺寸、格式和可读性检查；
7. 进行图片文字核对；
8. 绑定内容版本。

图片文件要求：

- 使用平台支持的常见图片格式；
- 尺寸由发布适配器配置；
- 不得包含水印、密钥、内部路径；
- 不得使用来源素材的近似复刻；
- 关键事实必须能追溯到来源。

## 7. 生成清单

`generation_manifests` 保存：

- 技能及版本；
- 提示词版本；
- 模型能力；
- 实际模型；
- 输入摘要；
- 输出结构版本；
- 用量和耗时；
- 生成时间；
- 修订关系；
- 是否人工修改。

不保存密钥和完整系统指令。

## 8. 内容版本

以下变化创建新版本：

- 选中标题；
- 正文；
- 互动问题；
- 话题；
- 任一图片；
- 来源映射；
- 风险说明；
- 计划内容形态。

新版本创建后：

- 旧版本只读；
- 旧发布审批失效；
- 自动检查必须重新执行；
- 已排期任务退回待发布审批。

## 9. 错误代码

| 错误码 | 处理 |
|---|---|
| `APPROVED_TOPIC_MISSING` | 停止并检查审批 |
| `EVIDENCE_PACKAGE_STALE` | 返回研究核验 |
| `CONTENT_SCHEMA_INVALID` | 修复一次 |
| `UNSUPPORTED_FACT` | 删除或补充证据 |
| `IMAGE_GENERATION_FAILED` | 单张重试一次 |
| `IMAGE_TEXT_MISMATCH` | 阻断并重做图片 |
| `ASSET_WRITE_FAILED` | 保留文本，转人工或重试 |
| `CONTENT_DUPLICATE` | 提示调整角度 |

## 10. 验收条件

- `AC-004-01` 未批准选题无法生成正式内容版本。
- `AC-004-02` 每个版本至少包含两个标题候选。
- `AC-004-03` 正文包含限制条件和互动问题。
- `AC-004-04` 所有事实性数字具有来源映射。
- `AC-004-05` 视觉脚本先于图片生成并可独立检查。
- `AC-004-06` 图片文字与内容版本一致。
- `AC-004-07` 修改任一发布素材会创建新版本。
- `AC-004-08` 新内容版本会使旧发布审批失效。
- `AC-004-09` 生成清单可以复现当次配置但不泄露密钥。

## 11. 测试重点

- 没有审批；
- 证据包过期；
- 模型添加未提供数字；
- 标题超限；
- 图片部分成功；
- 图片错字；
- 文件写入中断；
- 内容版本并发修改；
- 人工修改后的来源一致性。
