# 规格十二：账号策略

## 1. 目标

把目标用户、价值主张、账号人格、内容支柱、红线和自动化边界保存为可审批、可版本化、可追溯的账号策略。

覆盖需求：

- `REQ-STR-001`
- `REQ-STR-002`
- `REQ-STR-003`
- `REQ-STR-004`
- `REQ-STR-005`
- `REQ-STR-006`

## 3. 状态

- `draft`
- `pending_approval`
- `active`
- `superseded`
- `rejected`

每个账号同一时刻只能有一个生效策略。

## 4. 创建与生效

流程：

```text
创建草稿
→ 确定性字段检查
→ 与当前策略比较
→ 展示影响范围
→ 运营者批准
→ 原子切换生效版本
→ 旧版本标记被替代
→ 新任务使用新版本
```

已经存在的内容任务继续使用创建时绑定的策略版本，除非运营者明确执行迁移。

## 5. 策略变更影响

变更分级：

### 5.1 重大变更

- 目标用户；
- 价值主张；
- 账号人格；
- 内容支柱；
- 红线。

重大变更必须：

- 人工批准；
- 展示受影响的待审批和制作中任务；
- 不自动迁移已有任务；
- 使依赖旧策略且尚未发布的内容进入人工复核。

### 5.2 一般变更

- 表达示例；
- 内容支柱描述；
- 非阻断性格式偏好。

一般变更仍创建版本，但可以选择仅应用于新任务。

### 5.3 运行策略变更

评论频率、研究频率和暂停状态属于自动化策略，不直接改写账号内容策略，但必须版本化和审计。

## 6. 策略消费

每个下游模块必须保存策略版本：

- 研究运行；
- 选题候选；
- 内容任务；
- 内容版本；
- 评论分类与回复；
- 复盘。

技能输入只接收完成当前任务所需的策略投影，避免把所有内部配置发送给模型。

## 7. 禁止自动修改

模型和复盘系统只能创建策略建议，不能创建生效策略。

禁止触发：

- 单篇爆款；
- 单篇低表现；
- 单周数据；
- 单条高赞评论；
- 单一热点；
- 模型自我判断。

策略建议必须包含证据、预期收益、风险和受影响范围。

## 8. 自动化控制

账号策略引用自动化策略：

- 研究是否启用；
- 制作是否启用；
- 发布是否启用；
- 评论是否启用；
- 评论类别白名单；
- 频率限制；
- 审批有效期；
- 发布时间允许窗口。

自动化策略变更立即影响尚未发生的外部动作，但不改变已有内容版本。

## 9. 错误代码

| 错误码 | 处理 |
|---|---|
| `STRATEGY_SCHEMA_INVALID` | 返回字段错误 |
| `STRATEGY_APPROVAL_REQUIRED` | 创建审批 |
| `STRATEGY_VERSION_CONFLICT` | 重新读取当前版本 |
| `STRATEGY_ALREADY_ACTIVE` | 幂等返回 |
| `STRATEGY_MIGRATION_REQUIRED` | 人工选择已有任务 |
| `STRATEGY_CHANGE_UNAUTHORIZED` | 拒绝并审计 |

## 10. 验收条件

- `AC-012-01` 每个账号同一时刻只有一个生效策略。
- `AC-012-02` 策略修改创建新版本，不覆盖历史。
- `AC-012-03` 新内容任务绑定当时的生效策略版本。
- `AC-012-04` 重大变更未经人工批准不能生效。
- `AC-012-05` 单篇和单周数据不能自动修改策略。
- `AC-012-06` 旧任务不会被无提示迁移到新策略。
- `AC-012-07` 下游产物可以追溯其策略版本。
- `AC-012-08` 暂停发布立即阻止尚未发生的最终发布动作。

## 11. 测试重点

- 同时批准两个策略版本；
- 策略批准与任务创建竞争；
- 人格变化时已有内容；
- 内容支柱删除；
- 自动化策略立即生效；
- 未授权策略修改；
- 旧策略回滚；
- 策略建议误触发生效。
