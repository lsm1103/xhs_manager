# 规格十一：运维、安全与恢复

## 1. 目标

定义系统配置、密钥、健康检查、日志、告警、备份、恢复和故障演练要求。

覆盖需求：

- `REQ-STR-006`
- `REQ-OPS-001` 至 `REQ-OPS-007`
- 产品需求文档第十五、十七节

## 2. 配置

配置分级：

1. 非敏感静态配置；
2. 账号策略；
3. 自动化策略；
4. 密钥；
5. 运行时暂停和熔断状态。

非敏感静态配置可使用文件或环境变量。密钥只通过环境变量或密钥服务注入。

启动时校验：

- 数据库路径；
- 素材目录；
- 备份目录；
- 飞书必要配置；
- 模型能力配置；
- 浏览器网关配置；
- 时区；
- 授权用户。

缺少发布必要配置时，系统可以以研究模式启动，但发布和评论保持暂停。

## 3. 密钥

密钥包括：

- 模型接口密钥；
- 飞书应用凭证；
- 浏览器网关令牌；
- 未来平台接口令牌。

要求：

- 不写入源代码；
- 不写入 SQLite 业务表；
- 不写入日志；
- 不写入飞书文档；
- 不传给内容技能；
- 错误消息只显示凭证类型，不显示值；
- 支持轮换后无代码重启或受控重启。

## 4. 健康检查

### 4.1 存活检查

只验证进程可响应，不调用外部服务。

### 4.2 就绪检查

验证：

- 数据库可读写；
- 迁移版本正确；
- 素材目录可写；
- 工作进程心跳；
- 调度进程心跳。

### 4.3 深度检查

按需执行：

- 飞书接口；
- 模型网关；
- 网页搜索；
- GitHub；
- OpenClaw；
- 小红书登录状态；
- 飞书文档。

深度检查不得执行发布或回复。

## 5. 暂停与熔断

`system_pauses` 保存：

- 范围；
- 原因；
- 创建者；
- 创建时间；
- 是否要求人工恢复；
- 恢复者；
- 恢复时间。

范围：

- 研究；
- 制作；
- 发布；
- 评论；
- 归档；
- 全部外部动作。

平台风控和错误账号触发的暂停必须人工恢复。

## 6. 日志

结构化字段：

- 时间；
- 日志级别；
- 服务；
- 任务；
- 工作流；
- 工作项；
- 连接器；
- 外部动作；
- 追踪标识；
- 耗时；
- 错误代码。

脱敏：

- 请求头中的授权字段；
- 回调密钥；
- 会话信息；
- 联系方式；
- 评论作者内部标识；
- 文件系统敏感路径。

不得记录完整模型系统指令。

## 7. 指标

基础指标：

- 接口请求次数和错误率；
- 工作项待执行数量；
- 最老待执行时间；
- 步骤成功率；
- 重试率；
- 租约超时次数；
- SQLite 锁等待；
- 外部连接器延迟和错误；
- 模型用量和结构失败；
- 发布成功、失败和未知；
- 评论发送和熔断；
- 飞书事件和卡片回调；
- 备份结果。

## 8. 告警等级

### 紧急

- 疑似绕过审批发布；
- 错误账号执行发布或回复；
- 疑似密钥泄漏；
- 重复发布；
- 数据库损坏。

### 高

- 发布结果未知；
- 评论平台风控；
- 登录失效；
- 数据库备份连续失败；
- 队列长时间无消费。

### 中

- 单一研究源不可用；
- 飞书文档归档失败；
- 模型结构输出连续失败；
- 指标采集窗口错过。

紧急和高等级通过飞书立即通知。

## 9. SQLite 设置

必须：

- 启用外键；
- 使用写前日志模式；
- 设置忙等待；
- 限制长事务；
- 使用迁移脚本；
- 禁止多个未经设计的工作进程同时写入；
- 定期执行一致性检查。

数据库文件、写前日志文件和共享内存文件必须处于同一受控存储环境。

## 10. 备份

备份内容：

- 一致性数据库备份；
- 内容素材；
- 策略与提示词版本；
- 关键浏览器证据；
- 配置清单，不含密钥。

周期：

- 数据库每日；
- 素材每日或发布后；
- 至少保留多个时间点；
- 每月恢复演练。

备份记录保存：

- 开始和完成时间；
- 备份类型；
- 文件校验值；
- 大小；
- 目标位置；
- 验证结果；
- 恢复演练状态。

## 11. 恢复

恢复步骤：

1. 暂停全部外部动作；
2. 恢复数据库和素材；
3. 执行迁移与一致性检查；
4. 检查成功外部动作；
5. 标记结果未知动作；
6. 恢复只读查询；
7. 人工确认后依次恢复研究、制作、发布和评论。

恢复后不得直接重新执行：

- `uncertain` 发布；
- `uncertain` 评论回复；
- 已过期审批；
- 超出时间窗口的发布计划。

## 12. 数据保留

建议默认：

- 审计日志：长期保留；
- 发布与审批记录：长期保留；
- 指标快照：长期保留；
- 浏览器普通快照：九十天；
- 异常关键证据：长期保留；
- 原始评论文本：按必要期限保留，知识库只留脱敏摘要；
- 临时上传文件：确认归档后清理。

具体期限必须可配置。

## 13. 故障演练

上线前必须演练：

- 工作进程崩溃；
- 调度重复触发；
- SQLite 暂时锁定；
- 数据库备份恢复；
- 飞书重复回调；
- 模型返回非法结构；
- OpenClaw 不可用；
- 登录失效；
- 发布成功但响应丢失；
- 评论对象漂移；
- 评论风控；
- 素材磁盘写满。

## 14. 错误代码

| 错误码 | 处理 |
|---|---|
| `CONFIG_INVALID` | 阻止相关能力启动 |
| `SECRET_MISSING` | 能力保持暂停 |
| `DATABASE_LOCKED` | 短暂重试一次 |
| `DATABASE_CORRUPT` | 紧急暂停并恢复 |
| `DISK_FULL` | 停止生成和发布 |
| `BACKUP_FAILED` | 告警 |
| `WORKER_STALLED` | 重启并检查租约 |
| `SECURITY_VIOLATION` | 紧急暂停 |

## 15. 验收条件

- `AC-011-01` 缺少发布凭证时系统不会启动发布能力。
- `AC-011-02` 日志和错误中不含明文密钥。
- `AC-011-03` 健康检查不会产生发布或评论副作用。
- `AC-011-04` 平台风控暂停只能由授权人工恢复。
- `AC-011-05` SQLite 备份可以成功恢复并通过一致性检查。
- `AC-011-06` 恢复后结果未知动作不会自动重放。
- `AC-011-07` 磁盘写满会阻止生成和发布。
- `AC-011-08` 紧急安全事件会暂停全部外部动作并告警。
- `AC-011-09` 所有关键故障演练具有记录和恢复结论。

## 16. 测试重点

- 密钥误写日志；
- 回调原文含敏感字段；
- 数据库锁等待；
- 备份时有写入；
- 恢复后工作项租约；
- 磁盘只读；
- 告警通道不可用；
- 暂停和恢复权限；
- 数据保留清理边界。
