# 规格九：飞书集成

## 1. 目标

把飞书作为运营控制入口，实现安全命令、双审批卡片、异常告警和人类可读归档。

覆盖需求：

- `REQ-FEI-001` 至 `REQ-FEI-008`
- `REQ-KNO-004`

## 2. 边界

飞书负责：

- 接收命令；
- 展示状态；
- 收集审批；
- 发送告警；
- 展示报告；
- 写人类可读归档。

飞书不负责：

- 保存权威任务状态；
- 决定审批是否有效；
- 同步执行长任务；
- 保存密钥；
- 替代数据库审计。

## 3. 事件入口

接收流程：

```text
接收请求
→ 校验签名和时间
→ 解析事件标识
→ 检查事件幂等
→ 校验用户权限
→ 转换为内部命令
→ 短事务写入
→ 快速返回
→ 异步处理
```

事件原文只按必要期限保存，日志使用脱敏摘要。

## 4. 用户权限

`feishu_authorized_users`：

- 飞书用户标识；
- 显示名；
- 角色；
- 状态；
- 授权时间；
- 撤销时间。

最小版本角色：

- `owner`

只有所有者能：

- 审批；
- 暂停或恢复；
- 重新排期；
- 人工接管；
- 修改策略；
- 导出数据。

## 5. 命令

支持自然语言入口，但内部必须解析为确定性命令：

| 用户意图 | 内部命令 |
|---|---|
| 开始本周选题 | `StartWeeklyResearch` |
| 研究某个主题 | `StartAdHocResearch` |
| 查看任务 | `GetTaskStatus` |
| 查看异常 | `ListIncidents` |
| 暂停发布 | `PauseAutomation` |
| 恢复发布 | `ResumeAutomation` |
| 查看周报 | `GetWeeklyReview` |

解析结果不确定时不得执行有副作用命令，只返回澄清提示。

## 6. 卡片状态

卡片显示状态：

- 待处理；
- 已批准；
- 已驳回；
- 待修改；
- 已延期；
- 已过期；
- 已失效；
- 处理失败。

卡片按钮携带最少数据：

- 审批请求标识；
- 操作；
- 卡片操作标识。

资源版本和权限从数据库重新读取，不相信客户端隐藏字段。

## 7. 选题卡片

卡片正文由规格五定义。卡片操作回调只调用审批应用服务。

重复操作：

- 相同操作标识返回原结果；
- 已处理审批返回当前状态；
- 旧卡片返回最新卡片入口；
- 不创建重复制作任务。

## 8. 发布卡片

图片优先作为飞书附件或可访问预览发送。卡片必须明确：

- 这是发布审批；
- 审批对应版本；
- 批准后系统会在何时自动发布；
- 修改任何素材后需要重新审批。

若素材预览未成功送达，不允许批准发布。

## 9. 异常通知

必须通知：

- 登录失效；
- 发布结果未知；
- 发布第二次失败；
- 评论熔断；
- 研究关键事实无法核验；
- 图片检查持续失败；
- 数据库备份失败；
- 工作队列停滞。

异常卡片只给出一个推荐人工动作，避免一次要求用户完成多个技术步骤。

## 10. 文档归档

归档内容：

- 周选题；
- 已发布内容清单；
- 单篇复盘；
- 周复盘；
- 用户问题地图；
- 已确认知识条目；
- 重大异常与恢复结论。

归档写入使用独立工作项。写入失败：

- 不回滚已完成发布；
- 创建待补归档；
- 最多自动重试一次；
- 持续失败后告警。

## 11. 幂等

唯一键：

- 飞书事件标识；
- 卡片操作标识；
- 归档文档＋业务对象＋版本。

数据库提交成功后才确认事件处理成功。

## 12. 安全

- 验证签名；
- 限制时间偏差；
- 只接受配置来源；
- 校验用户；
- 卡片回调不携带密钥；
- 文档不写浏览器会话；
- 评论中的联系方式归档前脱敏；
- 管理命令写审计。

## 13. 错误代码

| 错误码 | 处理 |
|---|---|
| `FEISHU_SIGNATURE_INVALID` | 拒绝 |
| `FEISHU_EVENT_DUPLICATE` | 返回原结果 |
| `FEISHU_USER_UNAUTHORIZED` | 拒绝并审计 |
| `FEISHU_COMMAND_AMBIGUOUS` | 请求澄清 |
| `FEISHU_CARD_STALE` | 返回最新入口 |
| `FEISHU_PREVIEW_INCOMPLETE` | 阻止审批 |
| `FEISHU_DOCUMENT_WRITE_FAILED` | 补偿任务 |

## 14. 验收条件

- `AC-009-01` 未授权用户无法执行审批和管理命令。
- `AC-009-02` 重复事件不会产生重复任务。
- `AC-009-03` 长任务会快速返回已受理而非同步等待。
- `AC-009-04` 旧卡片不能审批新版本。
- `AC-009-05` 预览未送达时不能批准发布。
- `AC-009-06` 文档写入失败不影响已发布状态。
- `AC-009-07` 异常通知包含已完成进度和单一人工动作。
- `AC-009-08` 飞书不是任务权威状态源。

## 15. 测试重点

- 签名错误；
- 重放攻击；
- 重复回调；
- 旧卡片；
- 未授权群成员；
- 卡片已批准后再次点击；
- 图片附件失败；
- 飞书超时但数据库已提交；
- 文档部分写入。
