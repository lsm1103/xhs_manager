## 当前产品基线

- 新建 AI 技术科普小红书账号；
- 目标用户是希望从对话式 AI 进阶到可运行工作流的人；
- 账号人格是“AI 工作流实验员”；
- 每周五篇图文；
- 研究、制图、排期、审批后发布、低风险评论回复、统计和归档自动执行；
- 选题和发布前必须人工审批；
- 飞书是控制入口，SQLite 是权威状态源；
- 首批研究源是网页搜索、GitHub 和小红书；
- 第一阶段验证涨粉、内容方向和用户问题，不销售明确产品。

## 已实现

- SQLite 与 Alembic 迁移；
- 内容任务状态机；
- 持久工作项和租约；
- 命令及外部动作幂等；
- 选题和发布双审批领域服务；
- 飞书标准化回调、白名单和重复事件处理；
- 自动化暂停、审计和健康检查；
- 研究运行、来源执行、标准化信号、确定性去重和证据包的内部审阅接口；
- 已接入经审批后的小红书草稿准备执行器；公开发布与评论仍保留人工确认边界。

## 后续开发顺序

1. 飞书企业自建应用适配器；
2. 可替换的只读研究连接器与研究确认后的选题引擎；
3. 内容与图片；
4. 小红书发布；
5. 评论；
6. 数据、复盘与知识库；
7. 端到端故障演练。

实现时每个开发任务都应引用对应规格中的验收条件。
