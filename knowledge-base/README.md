# 运营知识库

## 当前重点

- 产品处于第一阶段可靠性骨架。
- 真实发布和评论保持关闭。
- 下一步是飞书企业自建应用适配器、研究和选题。

## 固定索引

- 账号：`knowledge-base/accounts/`
- 选题：`knowledge-base/topics/`
- 模式：`knowledge-base/patterns/`
- 动作：`knowledge-base/actions/`
- 复盘：`knowledge-base/reviews/`

## 当前有效规则

1. 选题和发布必须分别审批。
2. 审批绑定不可变版本。
3. 外部动作结果未知时先核验，不自动重放。
4. 自动失败最多重试一次。
5. 飞书自定义群机器人只用于通知，交互审批需要企业自建应用机器人。
