AI WORKFLOW

/ 4 STEPS

02 / 对比CHAT ≠ FLOW

先分清两件事

一次聊完
不等于下次
还能做完

聊天

靠记忆

上下文换了、提问换了，结果就容易跟着漂。

工作流

靠约定

谁来做、怎么做、做到什么算完成，都能回看。

关键不是更长的提示词，而是更稳定的边界。

03 / INPUT先固定输入

第一步

别只说
“帮我做一下”

INPUT TEMPLATE

把起点写清楚

目标是什么？现有资料在哪？限制条件有哪些？交付物要长什么样？

有

明确的素材、范围、格式

没有

一句模糊的“你看着办”

输入越清楚，后面的判断就越少靠猜。

04 / PROCESS把中间过程拆开

第二步

让每一步
都能被替换
和复查

01

调研

找来源

02

判断

选方向

03

生产

出成品

每一步都留下输入和输出，问题才知道该从哪里改。

不是“让 AI 自己想”，而是把责任交接写出来。

05 / CHECK补上终点

第三、四步

验收
再归档

✓

验收

标题、事实、格式、素材、风险，逐项确认。

→

归档

把可复用的提示、素材和结论放回固定位置。

没有验收的输出只是草稿；没有归档的经验下次还要重来。

06 / START今天就能开始

最小版本

先把
重复的一件事
写下来

4-STEP NOTE

输入：我给了什么
步骤：我怎么推进
验收：什么算完成
归档：下次从哪里开始

这是我给自己搭的最小模板，不是万能自动化。先跑一轮，再改一轮。
